# JobScraper-Cloud → personal: what to port

Read-only research, 2026-11-01. Nothing was written in either repo.

- **Personal (target):** `JobScraper`, branch `personal`, HEAD `7c4ed08`.
- **Cloud (source):** `JobScraper-Cloud`, `master` = `origin/master` = `c08633c`.

## 0. How the two repos relate, and the easiest way to port

- **They share git history.** Cloud contains personal's commits up to `09abb3d` (M16). Cloud cherry-picked or re-did M17 (`b53292b`), the index.html no-cache fix (`2e2051c`), refactor-clean (`b917c80`) and OVERVIEW (`46b4e81`). Personal-only commits since the fork are `227a921` (Companies/Runs rework, CountPicker, `/` search), `c3e1c30` (28 SG boards) and `7c4ed08` (docs). Cloud has none of these.
- **Best port source: cloud commit `019e975` (2026-10-08).** This is the last snapshot where the engine is still SQLite (`src/jobscraper/store/legacy_sqlite.py`) and the judge prompt is still the personal one (`PROMPT_VERSION = "v2-combined-1"`, "new graduate software engineer", `DEFAULT_INTERESTS`). By then it already has D-33 faceting, H1 (posting closure, logging, healthz, toast), the small-model backstops and the scheduler grace. Diffing personal HEAD against `019e975` shows almost nothing but those additions:

### 3a. Things in personal that cloud removed on purpose. Do not import their removal.

Never copy these cloud files wholesale:
